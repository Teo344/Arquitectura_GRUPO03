Comercializadora de teléfonos celulares - Servicios REST (Grupo 03)

Base: /api/v1. Salvo el inicio de sesión, todo exige la cabecera Authorization: Bearer <token>. Los errores responden application/problem+json.

  • POST api/v1/sesiones {usuario, clave} iniciar sesión (público)
  • DELETE api/v1/sesiones/actual cerrar sesión
  • GET api/v1/telefonos catálogo · GET api/v1/telefonos/{codTelefono}
  • POST api/v1/telefonos {marca, modelo, precio} · PUT api/v1/telefonos/{codTelefono} · DELETE api/v1/telefonos/{codTelefono}
  • GET api/v1/clientes/sujeto-credito?cedula={cedula} evaluación y monto máximo
  • GET api/v1/clientes/creditos?cedula={cedula} créditos del comprador
  • GET api/v1/creditos/{codCredito}/cuotas tabla de amortización
  • GET api/v1/creditos/simulacion?monto={monto}&cuotas={n} tabla sin guardar
  • POST api/v1/facturas {cedula, formaPago, numCuotas, detalles:[{codTelefono, cantidad}]} vender
  • GET api/v1/facturas/{numFactura} · GET api/v1/facturas?cedula={cedula}
