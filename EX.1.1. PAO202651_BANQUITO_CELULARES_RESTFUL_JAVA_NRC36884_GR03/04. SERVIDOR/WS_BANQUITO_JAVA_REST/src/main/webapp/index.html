BanQuito - Servicios REST del módulo de crédito (Grupo 03)

Base: /api/v1. Todas las peticiones exigen la cabecera X-Api-Key. Los errores responden application/problem+json.

  • GET api/v1/clientes?cedula={cedula} buscar cliente
  • GET api/v1/clientes/sujeto-credito?cedula={cedula} 1. ¿es sujeto de crédito?
  • GET api/v1/clientes/{codCliente}/monto-maximo 2. monto máximo
  • POST api/v1/creditos {codCliente, monto, numCuotas} 3. otorgar crédito (201 + Location)
  • GET api/v1/creditos/{codCredito}/cuotas 4. tabla de amortización
  • GET api/v1/creditos/{codCredito} crédito con su tabla
  • GET api/v1/clientes/{codCliente}/creditos créditos de un cliente
  • GET api/v1/creditos/simulacion?monto={monto}&cuotas={n} tabla sin guardar
