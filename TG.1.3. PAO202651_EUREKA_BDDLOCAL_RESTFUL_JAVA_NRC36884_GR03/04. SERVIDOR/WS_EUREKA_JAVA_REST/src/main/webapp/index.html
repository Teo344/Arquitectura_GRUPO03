EurekaBank - Servicios REST (Grupo 03)

Base: /api. Los recursos protegidos exigen la cabecera Authorization: Bearer <token>.

  • POST api/autenticacion/login (público) {usuario, clave, equipo}
  • POST api/autenticacion/cerrar-sesion (token)
  • GET api/cuentas/{cuenta} (token)
  • GET api/cuentas/{cuenta}/movimientos (token)
  • POST api/transacciones/depositos (token) {cuenta, importe}
  • POST api/transacciones/retiros (token) {cuenta, importe}
  • POST api/transacciones/transferencias (token) {cuentaOrigen, cuentaDestino, importe}
